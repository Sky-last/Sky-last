## 🚧 Sedang Dikerjakan

> **👶 Growmon** — Aplikasi pemantauan tumbuh kembang anak (0–24 bulan) berbasis **Standar Antropometri WHO**, **KPSP**, dan panduan **MPASI/Gizi Kemenkes 2024**.
>
> Z-Score otomatis, skrining perkembangan, rekomendasi gizi personal, mode offline + sinkronisasi, hingga dashboard tenaga kesehatan.
